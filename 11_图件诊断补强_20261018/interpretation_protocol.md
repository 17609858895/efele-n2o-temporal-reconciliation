# Frozen interpretation protocol

This is a post-development explanation of the frozen round-08 estimators. It does not select models, change predictions used in the benchmark, or create an external validation set.

1. Replay the eight outer LightGBM fits with their saved configurations and training-only inputs. Require maximum prediction discrepancy below 1e-9. Replay the original TabPFN v2 raw-target estimator with four ensemble members, seed 20261018 and the original checkpoint. Preprocessor caching may be used only if predictions match the frozen predictions within absolute 3e-4 plus relative 1e-5 and pooled daily R2 differs by less than 1e-5; otherwise use the original low-memory mode. Each query uses the original row order and batches of 256.
2. Use all 3,319 observed days in the eight held-out management cycles, retaining negative fluxes and extreme days. Keep the original observation support for centering and all fixed affine coefficients.
3. Partition all 42 features into six declared groups. Within each held-out treatment and cycle, circularly shift the entire group's calendar trajectory by floor(n/3) and floor(2n/3) days. Group members move together. This preserves group distributions and most temporal dependence but breaks alignment with other groups. It measures **within-cycle temporal alignment reliance**, not complete feature importance: treatment identity and other cycle-constant features cannot be assessed by these shifts. Cross-group dependence may be disrupted, so effects are model diagnostics, not physical interventions.
4. For the level head report the change in RMSE of the two treatment-specific cycle means; for the shape head report the change in RMSE after centering both predictions and observations separately within treatment. Average the two shifts within each held-out cycle, show all eight cycle results, and separately report pooled metrics across all cycles. Negative changes remain visible. Fold ranges are descriptive, not confidence intervals.
5. Evaluate fixed local input perturbations: soil temperature +1 degree C; WFPS +5 percentage points; and their joint perturbation. Bound the increment by the outer-training observed-day maximum and leave any held-out input already outside the outer-training range unchanged; record actual changes. Other inputs and the models remain fixed. For the level head, b times the rowwise LightGBM prediction change is the contribution whose observed-day mean changes the calibrated cycle level. For the daily-shape head, center each TabPFN perturbed output on the same observation dates before differencing. Both are in original flux units. The joint response minus the two single-input responses is a local non-additivity diagnostic, not causal interaction evidence.
6. Display input-supported response maps only where at least 20 observed rows from at least three held-out cycles occur. Use fixed 5 x 5 pooled input-quantile bins; aggregate within each cycle first and then average cycles equally. Display counts in a companion table. For one-dimensional response summaries use eight input-quantile bins, the same support rule, and show between-cycle ranges rather than confidence intervals. These bins affect visualization only and are set without looking at response values.
7. Freeze source hashes before fitting. Preserve every baseline and perturbation output, numerical reproduction checks, metric tables, feature definitions and plotting code. Scientific limitations go into the manuscript companion text as well as internal notes. Interpretation does not establish soil nitrogen mechanisms or remedy the absence of independent external validation.

Primary methodological reference: scikit-learn, Permutation feature importance and its correlated-feature example, https://scikit-learn.org/stable/modules/permutation_importance.html and https://scikit-learn.org/stable/auto_examples/inspection/plot_permutation_importance_multicollinear.html (accessed 2026-10-18). The circular-shift design above is a task-specific diagnostic, not a reproduction of ordinary row permutation.
